# AntiCheatingQuiz

Personalized paper MCQ exams that make bathroom Instagram answer-key sharing useless. Instructors upload a 10-question bank and roster; the app builds one Letter sheet per student—shuffled order, shuffled A–D, and unique numbers—plus a QR for phone grading. Print the whole class from one combined PDF, open the private link once on your phone, scan each sheet, tap the bubbles, and export CSV. Built on Cloudflare Workers + D1 for a Replit-friendly prototype for real classrooms (~40 students).
